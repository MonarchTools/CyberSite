# CyberSite

ساختار اولیه پروژه با Flask و الگوی Application Factory و Blueprintها.

## اجرا

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # در ویندوز: copy .env.example .env
python create_admin.py      # ساخت حساب مدیر
python run.py
```

سپس آدرس `http://127.0.0.1:5000` را باز کنید.

تنظیمات محرمانه را در فایل `.env` قرار دهید و آن را در Git منتشر نکنید.

## فروشگاه

- لیست محصولات: `/products/` (جستجو، فیلتر دسته، مرتب‌سازی، فقط موجود، صفحه‌بندی)
- جزئیات محصول: `/products/<id>`
- سبد خرید و ثبت سفارش: `/shop/cart`
- مدیریت محصولات: `/products/manage` — مدیریت سفارش‌ها: `/shop/manage/orders` (نیاز به ورود)

قیمت‌ها به **ریال** و به صورت عدد صحیح ذخیره می‌شوند.

### پرداخت

در `.env` مقدار `ZARINPAL_MERCHANT_ID` را بگذارید. برای آزمایش بدون پرداخت واقعی
`PAYMENT_GATEWAY=mock` و `FLASK_DEBUG=1` را تنظیم کنید؛ درگاه آزمایشی در حالت
غیر‌توسعه به‌طور خودکار غیرفعال است.

### به‌روزرسانی از نسخهٔ قبلی دیتابیس

ستون `products.price` از `Numeric(12,2)` به عدد صحیح ریالی تغییر کرده است و
`db.create_all()` ستون‌های موجود را تغییر نمی‌دهد. اگر قبلاً محصول ثبت کرده‌اید،
قبل از اجرا از `instance/cybersite.db` نسخهٔ پشتیبان بگیرید و قیمت‌ها را یک‌بار
بررسی کنید (یا دیتابیس را پاک و دوباره بسازید).

## فرم تماس

- فرم عمومی در `/contact/` با کپچا، فیلد تلهٔ ضد ربات و محدودیت ۵ پیام در ساعت برای هر IP (`CONTACT_MAX_PER_HOUR` در `config.py`). IP خام ذخیره نمی‌شود، فقط یک هش آن.
- صندوق پیام: `/contact/manage` (نیاز به ورود) با فیلتر خوانده‌نشده، مشاهده و حذف؛ تعداد پیام‌های جدید روی کارت «پیام‌ها» در داشبورد دیده می‌شود.
- پیام‌ها فقط در پنل ادمین نمایش داده می‌شوند؛ ایمیل یا پیامک اطلاع‌رسانی ندارد.

## امنیت پنل ادمین

- **SECRET_KEY اجباری است.** بسازید و در `.env` بگذارید:
  `python -c "import secrets; print(secrets.token_hex(32))"`
  (فقط با `FLASK_DEBUG=1` بدون کلید هم اجرا می‌شود و کلید موقت می‌گیرد.)
- ورود با **کپچا** و **قفل تلاش ناموفق**: بعد از ۵ تلاش اشتباه (رمز یا کپچا) آن IP به مدت
  ۱۵ دقیقه قفل می‌شود (`LOGIN_MAX_ATTEMPTS` و `LOGIN_LOCK_MINUTES` در `config.py`).
- نشست مدیر بعد از ۸ ساعت بی‌فعالیتی منقضی می‌شود.
- هدرهای امنیتی (CSP، X-Frame-Options و …) برای همهٔ پاسخ‌ها ارسال می‌شود. اسکریپت یا
  استایل inline در قالب‌ها نگذارید؛ CSP آن را مسدود می‌کند.
- پشت **Nginx** یا هر پروکسی دیگر، `TRUSTED_PROXY_COUNT=1` بگذارید تا قفل ورود IP واقعی
  را ببیند؛ وگرنه همهٔ کاربران یک IP دیده می‌شوند. اگر پشت پروکسی نیستید صفر بماند.
- روی HTTPS مقدار `SITE_URL=https://...` را بدهید تا کوکی `Secure` و HSTS فعال شود.
